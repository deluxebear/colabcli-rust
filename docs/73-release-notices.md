# 发行声明与源码扫描准备

## 已实现行为

[发行工具](../tools/package_release.py) 现在把 [上游来源声明](../THIRD_PARTY_NOTICES.md) 与三份原始许可证复制到候选目录并纳入 SHA256SUMS。声明区分 Google CLI、Kernel Client、后者注明的 Jupyter Server 来源，以及尚缺复用授权确认的 colab-ext；不替用户选择项目自身的整体许可证。

输入声明须为非空、非符号链接的普通 UTF-8 文件，最大 1 MiB。失败时清理暂存目录，不留下可被误用的部分发行目录；已有输出目录继续禁止覆盖。二进制名称、更新清单 schema、安装流程保持原契约。

## 验证与限制

发行工具 10 项临时目录测试通过，新增声明字节/校验和检查及缺失、空、符号链接、目录、非法编码的失败清理。全量 Python 工具测试 178 项：177 通过、1 跳过。本轮没有修改 Rust，也没有重新构建或运行真实云资源。

对 git ls-files --cached --others --exclude-standard 所列 366 个普通文件建立临时源码快照并运行 Gitleaks，启用完整脱敏且忽略内联 allow 注释。扫描退出 1，475 条命中均为 research JSON 中文件/模块/合成账户文件的 64 位十六进制哈希值；没有增加整目录白名单。该结果仍须结合来源审阅，不作为所有秘密绝对不存在的证明。原始脱敏报告留在被忽略的 target/release-source-gitleaks.json，不发布本机绝对路径。

公开仓库尚无分支与 Release。colab-ext 的复用权利确认、完整依赖声明、源码推送、远程四平台构建与真实 Release 下载验收仍未完成；本轮仅关闭候选包缺少已知上游声明的具体缺口。
